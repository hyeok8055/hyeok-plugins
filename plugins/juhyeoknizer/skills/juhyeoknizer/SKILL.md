# 주혁나이저

윤주혁의 문장 호흡과 서식을 적용한다. 추상적인 수식어를 덜고 누가 무엇을 했는지 읽히는 문서를 만든다. 문체 규칙은 사용자가 제공한 선호이며, 실제 경력이나 과거 저술을 입증하는 자료가 아니다.

## 적용할 모드

- 보고서, 공모전 기획서, 제안서: [report.md](references/report.md)를 읽는다.
- 이력서, 경력기술서, 자기소개서: [resume.md](references/resume.md)를 읽는다.
- 그 밖의 개인 글, 혼합 문서, Sol/Luna 작업 분담과 검사기 사용: [adaptive-writing.md](references/adaptive-writing.md)를 읽는다.
- 변환 예시가 필요할 때만 [examples.json](references/examples.json)을 읽는다. 세 예시는 모두 가상이며 사용자 이력이 아니다.

## 공통 원칙

1. 초안과 사용자 메모에서 사실, 가정, 제안한 작업을 구분한다. 날짜, 수치와 단위, 담당 범위, 성과, 고유명사, 부정 표현, 불확실성, 계획/완료 상태를 보존한다. 경험의 주체나 검증 수준을 높여 쓰지 않는다.
2. 통계, 법령, 서비스 비판은 제공되었거나 실제 확인한 근거만 쓴다. 없는 수치나 법적 의무를 만들지 않는다. 필수 근거가 빠졌으면 본문 밖에 필요한 자료를 짧게 적거나 초안에 미확인으로 남긴다. 제출본에 남은 미확인 부분은 알린다.
3. 새로 쓰는 문장에는 가운데점 U+00B7을 사용하지 않는다. 비슷한 점 기호로 우회하지 않는다. 쉼표, 슬래시, 접속어 또는 문장 분리를 문맥에 맞게 고른다. 보고서용 작은 원 기호 U+25E6은 사용자가 허용한 계층 기호다.
4. URL, 코드, 식별자, 공식 명칭, 직접 인용의 원문은 보존한다. 그 안의 금지 기호는 일괄 치환하지 않는다. 정확한 인용이 불필요하면 의미를 보존해 간접 인용한다. 원문 보존 때문에 기호가 남으면 본문 밖에 보존 이유를 한 줄로 알린다.
5. '시너지 창출', '고객 경험 제고', '유기적으로 협업' 같은 말은 실제 행동과 관찰 결과로 바꾼다. 쉼표로 행동을 끝없이 잇지 않는다. 모든 항목을 같은 문제/행동/결과 틀에 끼워 넣지 않는다. 오류나 어색함을 일부러 넣어 자연스러움을 흉내 내지 않는다.
6. 문서 본문부터 제시한다. 마크다운은 요청된 출력 형식에서만 쓴다. 일반 텍스트 제출란에는 굵게 표시, 코드 울타리, 링크 문법 등이 남지 않도록 렌더링 결과를 옮긴다. 형식과 분량이 명확하면 다시 묻지 않는다.

## 작성과 검토

- 독자, 목적, 형식, 분량과 근거 범위를 파악하고 해당 모드만 읽는다.
- 먼저 논리와 사실을 맞춘 뒤 문장 호흡을 다듬는다. 내용이 이미 타당하면 필요한 부분만 고친다.
- 최종 문장에서 새 수치, 과장된 역할, 삭제된 한계, 제안이 실적처럼 바뀐 부분을 원문과 대조한다. 숫자가 없어도 구체적인 행동과 산출물이 있으면 유지한다.
- 텍스트 파일을 검토할 때는 `scripts/check_prose.py`를 쓸 수 있다. [사용법과 한계](references/adaptive-writing.md#검사기)를 따른다. 검사는 읽기 전용이며 AI 작성 여부나 사실의 진위를 판정하지 않는다.
- 문제 위치를 검토해 수동으로 고친다. 문서의 논리와 의미까지 확인한 뒤 결과를 전달한다. 요청하지 않은 진단 보고서를 본문에 덧붙이지 않는다.

## 실행 범위

현재 세션의 허용된 OpenAI 모델과 도구로 수행한다. 모델 역할은 작업 권장 사항이며 설정 파일이나 모델을 자동 변경하지 않는다. 외부 AI/API, MCP 설치, 자동 에이전트 생성, 개인 홈 설치는 이 스킬에 포함되지 않는다. 자료 확인이 필요할 때만 이미 제공된 검색 도구나 사용자가 설정한 MCP를 범위에 맞게 탐색한다.

공모전/시험에서는 주최측의 최신 조건이 이 스킬보다 우선한다. 문서 작성 요청을 사전 체험이나 시험 시작으로 확대하지 않는다. AI 사용이 금지된 서술형 단계에서는 초안, 교정, 답안 생성을 수행하지 않는다. 평가 중의 세부 도구 제한은 [adaptive-writing.md](references/adaptive-writing.md#평가-맥락)를 따른다.

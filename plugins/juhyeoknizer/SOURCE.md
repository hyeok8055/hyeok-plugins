# 주혁나이저 출처와 구현 이력

2026-10-31: 윤주혁이 제공한 글쓰기 지문과 편집 선호를 기준으로 Codex용 개인 작성 스킬을 새로 작성했다. 기존 한국어 휴머나이저의 역할을 대체하는 단일 writer다. 기존 스킬명으로 연결하는 alias, 실행 의존성, compatibility 경로는 없다.

pin과 라이선스 정보는 이 저장소에 보관되었던 `plugins/humanize-korean/SOURCE.md`와 `LICENSE`에서 확인했다. 위 pin은 기존 배포본의 고정 리비전 기록이며 최신 upstream 버전이라는 뜻이 아니다.

한국어 초안의 표현을 진단하고 고친 뒤 검토하는 작업 방식이 참고 배경이다. 주혁나이저의 코드, 스킬 본문, 예시는 독립 작성했으며 upstream 코드나 문서 본문을 복사하지 않았다. 원본 MIT 라이선스가 적용되는 legacy 파일은 백업할 때 해당 `LICENSE`와 함께 보존한다. 이후 원본 코드나 본문을 재사용한다면 해당 라이선스 고지도 새 배포물에 포함한다.

## 대체한 동작

- 사용자 지문을 보고서, 이력서, 일반 개인 글로 나누어 필요한 규칙만 읽는다.
- 통계 개수, 특정 분석 패키지, 여러 단계의 처리를 모든 문서에 강제하지 않는다.
- 가운데점 검사, 일반 텍스트의 Markdown 잔여 검사, 원문 수치와 보호 문자열 비교를 `scripts/check_prose.py`로 수행한다.
- 기존의 무거운 hard gate, 변경률 강제, AI 판별 점수, 모델 다중 호출은 가져오지 않았다. 경고는 편집 검토 사항이며 자동 수정이나 사실 판정이 아니다.
- 예시 세 개는 모두 합성 자료다. 사용자의 실제 이력이나 통계 근거로 재사용하지 않는다.

Codex 메타데이터와 패키징에 참고한 공식 문서는 [스킬 내부 설정 근거](skills/juhyeoknizer/references/adaptive-writing.md#설정-근거)에 정리했다. 플러그인 없이 스킬 폴더만 복사해도 실행에 필요한 참조와 스크립트가 모두 포함된다.

CLI 이식성 검토: 실제 스킬 경로에서 검사기를 찾고 작업 폴더의 문서를 입력하도록 실행 예시를 명확히 했다.

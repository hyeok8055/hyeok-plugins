# 주최측 규정 적용

공모전이나 감독형 평가 준비에만 읽는다. 주최측의 최신 안내와 과제별 README,
제공 환경의 제한이 이 모음집의 일반 작업 흐름보다 우선한다. 시험을 시작하거나
감독 동의, 촬영, 제출을 대신 조작하는 절차는 포함하지 않는다.

## SK하이닉스 AI 해커톤 2차 예선

2026-10-31에 안내 PDF 3개와 10월 29일의 '2차 예선 접속 링크 및 사전 체험 안내' 이메일을
확인한 기준이다. 해당 이메일이 기존 가이드와 충돌하면 이메일을 우선하라고 명시한다.
원본은 이 저장소에 재배포하지 않는다. 최신 안내나 당일 공지가 바뀌면 다시 확인한다.
같은 날 사용자가 제공한 `[general rule]`의 모델 권장 목록(Sol 6.1, Terra 5.6, Luna 6,
Sol 6.0)을 추가 반영했다. `[model target set]`은 권장 목록이며 규정보다 우선하는 실행 허가가 아니다.
규칙 충돌 시 `[general rule]`과 최신 주최측 안내를 우선한다.

공개 도구를 사용할 수 있다는 조건과 특정 서버에 자료를 보내도 된다는 조건은 별개다.
외부 소스의 일부 알고리즘과 공개 스킬은 과제 해결에 필요한 범위로 사용하며, 결과물 전체를
외부 완성본으로 대체하지 않는다. 출처와 차용 범위, 직접 구현한 내용, 검증 기록을 제공 환경 안에 남긴다.
문제, 파일, 결과물의 외부 전송은 모니터링 및 제재 대상이므로 문제 내용을 외부 스킬 검색어로도 보내지 않는다.
이 모음집의 공개 게시 작업은 시험 전 개인 개발 환경의 도구 준비다. 시험 작업 폴더에서는 Git push를 하지 않는다.
외부 문서 조회가 필요하면 공개 API명 등 일반 질문만 사용하고 제공 환경의 허용 범위를 확인한다.
판단이 안 되는 연결은 필수 흐름에서 제외하고 허용된 로컬 자료와 검증으로 진행한다.

## 구현과 검증

- 과제 README에서 목표와 필수 산출물을 확인한다. 예시 화면의 파일명이나 포트를 과제 조건으로 오인하지 않는다.
- 제공 환경에서 허용된 파일 편집, 터미널 실행, CLI 테스트와 정적 검증을 사용한다.
- 웹 서버는 실제 포트를 확인하고 플랫폼 가이드의 `0.0.0.0` 바인딩을 따른다.
  플랫폼 Browser의 화면과 입력 동작은 사용자가 직접 확인한다. AI는 시각 검증을 했다고 보고하지 않는다.
- 서브에이전트는 제공 환경에서 허용되는 기능과 모델로만 위임한다. 작업자 수를 고정하지 않고
  남은 시간, CPU/RAM, 실제 작업 분리에 맞춘다. 토큰 사용량이 간접 평가에 활용될 수 있음을 고려한다.
- 실무자 에이전트는 업무 맥락, Cofa Helper는 사용법과 제출 절차, 문제 신고는 반복 오류와 감독 연결 문제에 사용한다.
- 제출물 확정과 최종 제출 완료를 구분한다. 후속 서술형과 종료 안내까지 사용자가 진행한다.

원문 위치: 필수 확인사항 브리프 1쪽 제한 사항과 추가 안내사항,
응시환경 상세 가이드 3쪽 MCP 설정과 제출 문서, 4쪽 시간과 제출 및 후속 서술형,
5쪽 도구와 감독 규칙. Proctor 가이드는 장비와 촬영 준비에 적용한다.

이 문서는 확인한 규칙의 작업용 요약이다. 공모전의 허용을 인증하거나 최신 공지를 대체하지 않는다.

# Codex 작업 흐름

복합 작업에서 필요한 단계만 적용한다. 목표, 경로, 기한이 이미 있으면 그대로 사용한다.
단계가 바뀔 때 모든 참고문서를 다시 읽지 않는다.

| 단계 | 주 담당 권장 | 스킬, 플러그인, MCP 활용 | 다음 단계로 넘길 것 |
|---|---|---|---|
| 요구사항 확인 | Sol | 요청, README, 지침, 지정 문서 확인. 이슈, 문서 MCP가 연결돼 있으면 해당 항목만 조회 | 목표, 필수 산출물, 제약, 불확실성 |
| 근거 수집 | Sol이 범위 결정, Luna가 정해진 조사 | 로컬 검색 우선. 필요한 외부 사실만 연결된 검색, 문서, 데이터 MCP로 확인 | 출처, 필요한 사실, 누락 자료 |
| 설계, 작업 분할 | Sol | 기존 구현, 인터페이스 확인. 설명에 맵이 필요한 경우만 `archify` | 변경 경계, 인터페이스, 완료 기준, 담당 파일 |
| 구현 | Sol은 핵심, 연동, Luna는 범위가 명확한 작업 | 편집, 셸, 기존 테스트. 필요한 데이터만 MCP 조회. 산출물 형식에 맞는 스킬 선택 | 수정 파일, 실행 방법, 변경 이유 |
| 검증, 통합 | Sol이 전체 정합성 확인, Luna가 정해진 검증 | 실제 동작, 경계 조건, 회귀 확인. 산출물 스킬의 검증기 사용. 외부 쓰기가 있었다면 결과 조회 | 실제 명령, 결과, 실패 조건, 미검증 부분 |
| 산출물 정리 | Luna 초안 가능, Sol이 사실 확인 | 필요한 문서와 시각화 스킬, 한국어 기록물의 `juhyeoknizer` | 최종 파일, 판단 근거, 검증 증거, 한계 |
| 전달, 제출 | 현재 주 에이전트 | 요청한 저장 위치, 제출 형식 준수. 외부 발송, 배포, push는 기존 승인 범위 확인 | 결과 경로와 확인된 완료 상태 |

Sol/Luna 둘 다 있어야 진행할 수 있는 구조가 아니다. 한 모델만 허용되면 같은 완료 기준으로
그 모델이 수행한다. 역할 변경을 실제 모델 변경으로 오인하지 않는다.

새 스킬이나 도구 구성이 필요해지는 단계에서만 [스킬과 MCP 구성](skill-and-mcp-setup.md)을 읽는다.
공모전이나 필수 산출물이 여러 개인 과제는 [요구사항과 검증 연결](requirements-trace.md)을 활용한다.
시험의 모델, 도구, 자료 반출 범위는 [주최측 규정](organizer-rules.md)을 우선 적용한다.

## 작업 인계

위임할 때 필요한 정보만 전달한다. 전체 대화, 저장소, 스킬 내용을 반복해서 넘기지 않는다.

```text
목표: 사용자가 확인할 수 있는 결과
입력: 필요한 파일, 자료 위치, 확인한 사실, 출처
수정 범위: 담당 파일 / 읽기만 할 파일
제약: 허용 모델, 도구, 시간, 사용자 선택, 외부 쓰기 범위
완료 조건: 검증할 동작과 실행할 명령
반환: 변경 파일, 검증 결과, 실패, 불확실성, 필요한 결정
```

독립된 조사나 서로 다른 파일의 구현은 병렬화할 수 있다. 공통 인터페이스를 먼저 결정하고
한 파일의 최종 작성자는 한 명으로 둔다. 주 에이전트는 통합과 사용자 소통을 맡는다.
위임한 구현을 동시에 다시 만들지 않는다. 결과를 받은 뒤 diff와 검증 증거를 확인한다.

## 반복, 실패 처리

- 실패한 명령과 실제 오류로 원인을 좁힌다. 같은 요청을 표현만 바꿔 반복하지 않는다.
- 권한, 인증, 자료 부재는 모델을 바꿔도 해결되지 않는다. 필요한 정보만 요청하고 독립 작업은 계속한다.
- 설계 가정이 틀렸으면 주 담당자에게 근거와 선택지를 돌려준다.
- 같은 검증을 여러 모델이 의무적으로 반복하지 않는다. 미해결 위험이나 추가 변경이 있으면 다시 검증한다.
- 필수 검증을 실행할 수 없으면 빠진 검증을 명시한다. 실행 성공과 시각적 품질 확인을 구분한다.

## 시간 제한이 있는 작업

남은 시간과 제출 조건을 확인하고 요구사항, 작동하는 핵심 결과, 검증, 제출 시간을 먼저 확보한다.
문서, 시각화, 윤문은 요청된 산출물과 평가 기준에 필요한 만큼 수행한다. 마지막에 대규모 구조 변경이나
새로운 도구 설치를 시작하지 않는다.

과정 설명이 필요한 평가에서는 구현 중 선택 이유, 사용 근거, 테스트 결과, 한계를 간단히 기록한다.
AI가 금지된 후속 단계는 사용자가 직접 수행한다. 이 문서는 자동 제출, 감독 조작, 외부 전송을 허용하지 않는다.

# 요구사항과 검증 연결

필수 산출물이 여러 개인 공모전, 구현 과제, 보고서에서만 사용한다. 별도 관리 도구 설치 없이
기존 작업 문서에 필요한 행을 기록한다. 작은 수정은 이 표를 만들지 않아도 된다.

| ID | 요구사항 | 근거와 위치 | 우선순위 | 구현 또는 산출물 | 확인 방법 | 실제 결과와 증거 |
|---|---|---|---|---|---|---|
| R1 | 입력에서 확인한 조건 | README 절, 안내 페이지 등 | 필수 / 선택 | 파일, 화면, 문단 | 동작 또는 수용 기준 | 통과 / 실패 / 미실행, 증거 경로 |

확정된 조건, 합리적 가정, 확인이 필요한 내용을 구분한다. 설계하면서 추가한 목표를 주최측 요구사항으로
표기하지 않는다. 검증 결과에는 실제 실행 명령과 결과를 남기고 미실행 검사를 통과로 기록하지 않는다.
평가 환경의 작업 이력은 해당 환경 안에 보존하고 외부 저장소나 분석 서버에 보내지 않는다.

참고한 구조:
[OpenAI의 spec-to-implementation 스킬](https://github.com/openai/plugins/blob/main/plugins/notion/skills/notion-spec-to-implementation/SKILL.md),
[GitHub Spec Kit](https://github.com/github/spec-kit).
두 프로젝트의 런타임이나 외부 서비스를 설치하는 절차는 포함하지 않는다.
